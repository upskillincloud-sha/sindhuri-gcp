# Creation of Network and Subnet
## Steps to Create Network in GCP
1.Log in to the [Google Cloud Console](https://console.cloud.google.com/).

<img width="1910" height="977" alt="image" src="https://github.com/user-attachments/assets/6fea828b-35d7-4d10-be01-8957080a672c" />

2. Create a Hub_Folder and Hub-Network-Project.

<img width="1916" height="856" alt="image" src="https://github.com/user-attachments/assets/7121f279-d282-4f87-a67a-918c06347d21" />

2. Go to home.

<img width="1910" height="977" alt="image" src="https://github.com/user-attachments/assets/6fea828b-35d7-4d10-be01-8957080a672c" />

3.  Click on open project picker. select the Hub-Network-project. 

<img width="1910" height="853" alt="image" src="https://github.com/user-attachments/assets/edec94f2-59fc-40e4-af80-1155882ada14" />

4. Click on Navigational menu and hover on VPC Network and click on VPC Network.

<img width="1916" height="931" alt="image" src="https://github.com/user-attachments/assets/ac684df3-c394-4801-ad02-9c23e0450145" />

5. VPC Networks page is opened.

<img width="1919" height="889" alt="image" src="https://github.com/user-attachments/assets/32185643-219a-4ec6-ac81-9e1042677833" />

6.If you find above shown error click on continue.

<img width="1917" height="888" alt="image" src="https://github.com/user-attachments/assets/2fbd8073-0873-47e4-817b-a5ac99d62e22" />

7. Open Project picker, select Organization.

8. Now click on Navigational menu, click on Billing

<img width="1917" height="958" alt="image" src="https://github.com/user-attachments/assets/438e8af7-89a6-46c4-9f31-47ccba9208b4" />

9. Click on "Your Projects" 

<img width="1917" height="972" alt="image" src="https://github.com/user-attachments/assets/bb41451a-9389-4450-97ba-a74ae955fa01" />

10. Check if billing account is enable to the project(here billing account is already enabled.)

<img width="1917" height="972" alt="image" src="https://github.com/user-attachments/assets/bb41451a-9389-4450-97ba-a74ae955fa01" />

11.Go to Home page. 

<img width="1910" height="977" alt="image" src="https://github.com/user-attachments/assets/6fea828b-35d7-4d10-be01-8957080a672c" />

12. Now in project picker, select the project(Hub-Network-Project). 

<img width="1910" height="853" alt="image" src="https://github.com/user-attachments/assets/2dbe9ddc-a586-4928-9e4d-090950510737" />

13. Click on Navigational Menu. Hover in APIs and Services. Click on Library.

<img width="1912" height="912" alt="image" src="https://github.com/user-attachments/assets/f7032780-1497-43d2-99b2-0d433d20108c" />

14. API Library Page will be opened.

<img width="1916" height="862" alt="image" src="https://github.com/user-attachments/assets/63867ad2-f057-4b29-986e-1f56005108c4" />

<img width="1908" height="841" alt="image" src="https://github.com/user-attachments/assets/f9cc03ef-b91c-4160-aa83-c70ba899fc9a" />

<img width="1908" height="856" alt="image" src="https://github.com/user-attachments/assets/1795df02-65d4-4c7f-abf8-f886d5b57773" />

<img width="1919" height="889" alt="image" src="https://github.com/user-attachments/assets/32185643-219a-4ec6-ac81-9e1042677833" />
