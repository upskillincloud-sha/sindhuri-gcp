Welcome to the Google Cloud Platform (GCP) documentation hub. This wiki provides an overview of our cloud environment, core services, architecture standards, operational guidelines, and best practices for building and managing solutions on Google Cloud.

## About GCP

Google Cloud Platform (GCP) is Google’s cloud computing platform that offers scalable infrastructure, secure data storage, networking, databases, serverless computing, analytics, and machine learning services. GCP enables teams to deploy applications efficiently, automate workflows, and operate workloads using Google’s global, reliable infrastructure.
