# Gateway in GCP
In GCP, a gateway is a network component that acts as an entry or exit point for traffic between your VPC and external networks. Gateways are essential for routing, connectivity, and security in hybrid and multi-cloud architectures.

Internet Gateway in GCP is already present. We need to select the option(Default internet gateway) in Next Hop.
